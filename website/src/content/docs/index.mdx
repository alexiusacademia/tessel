## A whole app in a few lines

<div class="split">

```tessel
app Counter(width: 320, height: 200) {
    state count = 0

    VStack(spacing: 12) {
        Text("Count: {count}")
            .font(size: 32, weight: .bold)

        HStack(spacing: 8) {
            Button("-") { count -= 1 }
            Button("+") { count += 1 }
        }
    }
    .padding(24)
}
```

<Image src={counter} alt="The Counter app, showing Count: 3 with minus and plus buttons" />

</div>

Run it with `tessel run counter.tsl`. No project files, no imports, no build
configuration: a folder of `.tsl` files is a program.

## Why Tessel

<CardGrid>
	<Card title="Declarative" icon="puzzle">
		Describe what the screen shows for the current state. When state changes,
		Tessel updates the window for you.
	</Card>
	<Card title="Native and fast" icon="rocket">
		Programs compile through LLVM to small native executables. The UI is drawn
		on the GPU by Tessel's own renderer.
	</Card>
	<Card title="Few rules to learn" icon="open-book">
		One kind of block, value types only, no imports, and errors as optionals.
		Every error message says what to do next.
	</Card>
	<Card title="macOS and Windows" icon="laptop">
		The same code builds a `.app` bundle on macOS and an `.exe` on Windows.
	</Card>
</CardGrid>

## An IDE written in Tessel

<Image src={ide} alt="The Tessel IDE with a file explorer, a tabbed code editor and a problems panel" />

Type `tessel` in a project folder to open the Tessel IDE: a file explorer,
tabbed editor with syntax colors and live errors, and one-click run, build and
packaging. It's a Tessel app itself. [Read more](/start/ide/).
